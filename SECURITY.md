# Security policy

hoshi is a hobby terminal game. Its bridge reads GitHub events and local agent
events. A way for crafted events to run code, read files outside the game's
state directory, or leak a GitHub token is a security vulnerability.

Report vulnerabilities privately: <https://github.com/Sannrox/hoshi/security/advisories/new>.
Do not open a public issue.

hoshi has no releases yet; only the latest release will receive fixes.
