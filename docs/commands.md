# Command reference

Generated by `hoshi help --markdown`. Edit the command catalog, then run
`scripts/generate-help.sh`; do not edit generated files.

Bare `hoshi` opens the title screen. `hoshi --help`, `hoshi -h`, and
`hoshi help` print human help without accessing a save. CLI commands retain
their JSON output. `hoshi help TOPIC` and `hoshi COMMAND --help` show details.

## advise

Read suggestions without taking actions.

```text
hoshi advise
```

Uses the selected save and the same core rules as interactive play. Results use the versioned JSON envelope. A refused action does not bypass prerequisites or fair-play restrictions.

Example: `hoshi advise`

Environment: HOSHI_SAVE, HOSHI_BALANCE

## Flags

- `--offline `: Disable automatic network requests.
- `--update-check `: Opt in to background release checks for serve.
- `--help `: Human help (-h also works).
- `--version `: Build version (-V also works).
- `--save PATH`: Select a save.
- `--balance PATH`: Override balance configuration.
- `--seed SEED`: Initialize a deterministic harness or new-game seed.
- `--continue `: Continue the current interactive slot.
- `--no-portraits `: Use ASCII portraits.
- `--commentary `: Enable replay commentary.
- `--advisor `: Enable optional local advice.
- `--json `: Explicit JSON CLI mode.
- `--arena `: Opt in to the bot arena.
- `--self-play `: Opt in to balance self-play.
- `--demo `: Opt in to the governance demonstration.
- `--bind ADDRESS:PORT`: Server listen address (serve only).
- `--config DIR`: Server configuration directory (serve only).

## Environment

- `HOSHI_LOG`: Diagnostic log level: error, warn, info or debug.
- `HOSHI_SERVE_ADMIN_TOKEN`: Save-scoped admin secret for local support reports.
- `HOSHI_SAVE`: Save path when --save is absent.
- `HOSHI_BALANCE`: Balance configuration path when --balance is absent.
- `HOSHI_BUILD`: Build-time version annotation.
- `HOSHI_PORTRAIT_PROTOCOL`: Portrait protocol selection.
- `NO_COLOR`: Disable terminal colors.
- `HOSHI_SERVE_TOKEN`: Runtime bearer token for the selected save.
- `HOSHI_SERVE_TOKEN_FILE`: Read the runtime bearer token from this file.
- `HOSHI_SERVE_PUSH`: Enable optional web push.
- `HOSHI_SERVE_VAPID_PRIVATE`: Runtime push signing key; never stored in the save.
- `HOSHI_SERVE_VAPID_SUBJECT`: Push contact subject.
- `HOSHI_SERVE_OIDC`: Enable optional identity login.
- `HOSHI_SERVE_OIDC_ISSUER`: Identity issuer.
- `HOSHI_SERVE_OIDC_CLIENT_ID`: Identity client identifier.
- `HOSHI_SERVE_OIDC_AUTHORIZATION`: Identity authorization endpoint.
- `HOSHI_SERVE_OIDC_TOKEN`: Identity token endpoint.
- `HOSHI_VERSION`: Install script version selection.
- `HOSHI_CHANNEL`: Install script channel selection.
- `HOSHI_OFFLINE`: Suppress automatic network requests.
- `HOSHI_SKIP_VERSION_CHECK`: Suppress automatic network requests.

## Exit codes

0 success; 2 invalid input; 3 action refused; 4 save locked; 5 internal or save error.
